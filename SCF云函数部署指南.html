将政务看板迁移到腾讯云 SCF，实现云端定时自动更新，无需本地客户端在线。

前置条件

  • 腾讯云账号（已实名认证）
  • GitHub Personal Access Token（已有，复用 daily-briefing 的 Token）
  • 政务看板 GitHub 仓库已包含 zhengwu-kanban.html 模板文件
1登录腾讯云 SCF 控制台

打开 https://console.cloud.tencent.com/scf，选择区域为北京或广州（离数据源更近）。

点击左侧菜单「函数服务」→「新建」。

2创建云函数
配置项填写内容

故障排查

问题：函数执行超时

解决方案：将执行超时时间从 180 秒调整为 300 秒。部分政府网站响应较慢时可能需要更长时间。

问题：GitHub API 返回 401

检查 GITHUB_TOKEN 是否正确，Token 是否过期。GitHub Token 有效期通常为 90 天，过期后需重新生成。

问题：GitHub API 返回 404

检查 GITHUB_OWNER、GITHUB_REPO、GITHUB_BRANCH 是否正确。确认仓库中存在 zhengwu-kanban.html 模板文件。

问题：数据量不足（某些板块 0 条）

可能原因：

  • 政府网站临时不可用或改版
  • 网络波动导致部分数据源抓取失败
  • 时间窗口内确实无相关新闻

SCF 函数会在下一次定时触发时自动重试。如果持续为 0，检查 SCF 日志中各数据源的抓取状态。

查看执行日志

在 SCF 控制台 → 函数详情 →「日志查询」中查看每次执行的详细日志，包括各数据源抓取结果和分类统计。

后续优化建议

  • 如果抓取数据持续不足，可考虑在 SCF 中集成百度新闻搜索 API 作为补充数据源
  • 添加 SCF 内存缓存（10分钟），避免短时间内重复触发导致重复抓取
  • 添加邮件/微信通知，在函数执行失败时发送告警
  • 在原 WorkBuddy 自动化任务中添加检查逻辑：如果 SCF 已成功更新，则跳过本地执行
